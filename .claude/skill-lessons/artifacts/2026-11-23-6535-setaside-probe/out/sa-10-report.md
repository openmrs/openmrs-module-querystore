Now reads go through `read()`, which tries the current location first (`LocalStorageService.java`, `read(String, IOFunction)`), while `purgeData` still uses `getPath` and deletes the legacy copy. This needs a file in both places, for example a migration that copied legacy files without removing them. I can't show that never happens, so under the method it goes in as a question that names that condition.
