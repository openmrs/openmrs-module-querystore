  with all 2140 tests green · blocking · cost: 1 round".
- NEW, `#425`:24 — "**both numeric bounds pinned against DELETION but not against MOVEMENT** —
  `comma - start < 4` -> `< 3` left the whole build green while flipping ordinary grouped numbers
  (300,500; 1,234,500; 24,000,500) to admitted, which on this check produces a false report on a
  published key. The only case exercising that arm used a ONE-digit head group." · blocking · 1 round.
- And the remedy is the one that worked, `#425`:26 — "[r2, beyond brief] attacked the bounds in the

applies: `>=`->`==` is a tightening of a comparison, while `< 4` -> `< 3` tightens a threshold and
LOOSENS what the arm admits. A rule that needs that adjudicated is a rule that will be skipped.

**What it does not claim:** nothing about how many mutations are owed, and the existing four stay.

**Not proposed:** `#425`:31's own diagnosis — "harden Termination lists 'its comparison loosened'
