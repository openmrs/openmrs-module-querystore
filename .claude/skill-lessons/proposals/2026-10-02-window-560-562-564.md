> Its isolation guard then refuses a compound command that runs git, and `$PPID` on a `gate-state`

**Measured this pass** (`iso_window.py`, `git_compound2.py`), over the Bash calls INSIDE each session's
`EnterWorktree` … `ExitWorktree` window (or to end of transcript), in #562 `111381c1…` (window from

`c3fd0664…` (from L1356, the record behind 0.38.0's sentence). "Refused" = the result carries the guard's
text "This session is isolated in the worktree". "Runs git" = a `git` command word in the shell text with
heredoc bodies removed. "Compound" = a chain, heredoc, loop or `$(`.
- Compound commands that run git: **62 passed, 6 refused**.
- Compound commands that run no git: 217 passed, **22 refused** — e.g. #562 L1184 a heredoc into python
  editing docs, L1412 an `lsof`/`kill` chain, L1751 a python loop; #564 four `sed` calls with runtime
  values and one `mysql` call.
- A plain `python3 /abs/x.py …` or `bash /abs/x.sh …`: 32 calls, **0 refused**.
- #402 L1376, a plain unchained `~/.claude/pipeline/gate-state --owner $PPID pr-set …`: refused; L1385

  stays inside the worktree. Refusing to run it — a worktree-isolated session's git operations must

- Calibration: #402 L1371 (a chain running `git fetch`, refused) classifies as git/refused; #562 L1075
  (`git branch …; git status …`) as git/passed; #562 L1153 (a python heredoc FOLLOWED by `git diff
  --stat`) as git/passed — the first detector draft also counted a heredoc that only MENTIONED git, and
  stripping heredoc bodies fixed that before these figures were taken.

**Proposed text** (replaces the sentence above, in place):
> Its isolation guard then refuses what it cannot verify, git or not: split as its message says, or run
> the steps as a script by absolute path. It refuses `$PPID` on a `gate-state` line even unchained, so
> run `echo $PPID` by itself and pass that pid to `--owner`.

**Prunes:** the clause "a compound command that runs git" (measured narrower than the guard in one

**Evidence entry**, `evidence.md` *State*, after the "Added 0.38.0" entry: `*Added 0.38.1 — the rule it
